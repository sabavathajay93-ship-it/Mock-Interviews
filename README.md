# InterviewReady – Interview Practice Website

**Practice Today. Interview with Confidence.**

InterviewReady is a responsive interview practice website designed to help students and job seekers prepare for interviews. It provides practice questions for HR, Technical, and Project interview rounds, with a timer, answer submission, basic feedback, and a final practice summary.

## 🚀 Features

- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **HR Interview Practice:** Practice common HR and behavioral interview questions.
- **Technical Interview Practice:** Revise programming, OOP, database, and problem-solving concepts.
- **Project Interview Practice:** Prepare to explain projects, technologies, responsibilities, and challenges.
- **Timed Questions:** Answer each question within a 60-second time limit.
- **Answer Submission:** Type and submit answers directly on the website.
- **Basic Automated Feedback:** Receive suggestions based on answer length and relevant keywords.
- **Progress Tracking:** Track your current question and overall interview progress.
- **Practice Summary:** View your average practice indicator after completing the session.
- **Restart Option:** Start another practice session whenever you want.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript** – Interview questions, countdown timer, answer evaluation, and progress tracking.

## 💻 Getting Started

### Prerequisites

You need a web browser and a code editor such as Visual Studio Code.

### Installation and Setup

**Step 1: Clone the repository**

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/InterviewReady.git
```

**Step 2: Open the project folder**

```bash
cd InterviewReady
```

**Step 3: Open the website**

Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code.

No package installation or build process is required for this version.

## 📖 How to Use

1. Open the InterviewReady website.
2. Click **Start Practicing**.
3. Select HR Interview, Technical Interview, or Project Interview.
4. Click **Start Mock Interview**.
5. Read the displayed question.
6. Type your answer in the answer box.
7. Click **Evaluate Answer** to receive basic feedback.
8. Click **Next Question** to continue.
9. Review your practice summary after completing the questions.
10. Click **Practice Again** to restart.

## 🧠 How the Feedback Works

The current version uses rule-based JavaScript logic to provide a basic practice indicator.

It considers:
- The length of the submitted answer.
- The number of relevant keywords included.
- General suggestions related to the selected interview category.

**Note:** This is not real AI evaluation. The current version does not understand answers like an AI model, reliably verify technical correctness, or generate personalized feedback using an AI API.
